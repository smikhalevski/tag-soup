    • onComment?(input: string, startIndex: number, endIndex: number): void

      Called when a comment is read. Indexes point to the comment content between <!-- and -->.

      A forgiving tokenizer reads unrecognized markup like <!x>, <?x> and </#> as a bogus comment, with the content x, ?x and #.

      Parameters

      • input: string

        The input that indexes point to.

      • startIndex: number

        The start index of the comment content, inclusive.

      • endIndex: number

        The end index of the comment content, exclusive.

      Returns void

    OptionalonDoctype

    • onDoctype?(
          input: string,
          nameStartIndex: number,
          nameEndIndex: number,
          publicIdStartIndex: number,
          publicIdEndIndex: number,
          systemIdStartIndex: number,
          systemIdEndIndex: number,
      ): void

      Called when a DOCTYPE is read.

      A missing identifier has equal start and end indexes, so in <!DOCTYPE html> both identifiers are empty strings.

      DOCTYPE is read only in a document, before the first tag or text. A forgiving tokenizer reads the first DOCTYPE there and ignores the others, and a strict tokenizer throws a MarkupSyntaxError at DOCTYPE elsewhere.

      Parameters

      • input: string

        The input that indexes point to.

      • nameStartIndex: number

        The start index of the name, inclusive.

      • nameEndIndex: number

        The end index of the name, exclusive.

      • publicIdStartIndex: number

        The start index of the public identifier, inclusive.

      • publicIdEndIndex: number

        The end index of the public identifier, exclusive.

      • systemIdStartIndex: number

        The start index of the system identifier, inclusive.

      • systemIdEndIndex: number

        The end index of the system identifier, exclusive.

      Returns void

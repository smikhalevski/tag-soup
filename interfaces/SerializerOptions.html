    OptionalareSelfClosingTagsSupported

    areSelfClosingTagsSupported?: boolean

    If true then elements without children are written as self-closing tags (<a/>), otherwise as a start tag followed by an end tag (<a></a>). Void elements without children are always written as a start tag only.

    Default

    false

    OptionalareTagNamesCaseInsensitive

    areTagNamesCaseInsensitive?: boolean

    If true then the case of ASCII letters in tag names is ignored.

    Default

    false

    OptionalencodeAttribute

    encodeAttribute?: (value: string) => string

    Encodes attribute values. Use this method to encode HTML/XML entities. Values are written in double quotes, so " must be encoded.

    By default, attribute values aren't encoded.

    Type Declaration

    Example

    OptionalencodeText

    encodeText?: (text: string) => string

    Encodes text. Use this method to encode HTML/XML entities.

    Text of raw_text and script_data tags, comments, CDATA sections and processing instructions is written as is.

    By default, text isn't encoded.

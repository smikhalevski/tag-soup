    OptionalareNamespacesRecognized

    areNamespacesRecognized?: boolean

    If true then xmlns and xmlns:* attributes declare namespaces, and a tag gets the namespace that the prefix of its name is bound to, or the default namespace if the name has no prefix. Otherwise, tags have no namespace.

    <svg xmlns="http://www.w3.org/2000/svg" xmlns:xlink="http://www.w3.org/1999/xlink">
      <xlink:a/>
    </svg>

    Here svg has the namespace http://www.w3.org/2000/svg, and xlink:a has the namespace http://www.w3.org/1999/xlink.

    A tag can declare the namespace of its own name. A tag whose prefix isn't bound has no namespace. Attributes that declare namespaces are kept, and namespaces of other attributes aren't resolved by parsers. In a DOM, Element.getAttributeNS looks them up.

    Namespaces are recognized after tags and attributes are renamed, and attribute values are decoded.

    Default

    false

    OptionaldecodeAttribute

    decodeAttribute?: (value: string) => string

    Decodes attribute values. Use this method to decode HTML/XML entities.

    It's separate from decodeText because HTML decodes attribute values differently: &copy=2 stays intact in an attribute value, but becomes ©=2 in text.

    By default, attribute values aren't decoded.

    Type Declaration

      • (value: string): string

      • Parameters

        • value: string

          The attribute value to decode.

        Returns string

    Example

    import { decodeHTMLAttribute } from 'speedy-entities';

    createDOMParser({ decodeAttribute: decodeHTMLAttribute });

    OptionaldecodeText

    decodeText?: (text: string) => string

    Decodes text. Use this method to decode HTML/XML entities.

    Text of raw_text and script_data tags, comments, CDATA sections and processing instructions isn't decoded.

    By default, text isn't decoded.

    Type Declaration

      • (text: string): string

      • Parameters

        Returns string

    Example

    import { decodeHTML } from 'speedy-entities';

    createDOMParser({ decodeText: decodeHTML });

    OptionalrenameAttribute

    renameAttribute?: (name: string) => string

    Renames attributes. Use this method to normalize attribute names, for example to lower case in HTML.

    By default, attributes aren't renamed.

    Type Declaration

      • (name: string): string

      • Parameters

        • name: string

          The attribute name as it appears in the input.

        Returns string

        The attribute name that the parser uses.

    Example

    createDOMParser({ renameAttribute: name => name.toLowerCase() });

    OptionalrenameTag

    renameTag?: (name: string) => string

    Renames tags. Use this method to normalize tag names, for example to lower case in HTML.

    End tags get the name of the start tag that they end, since the tokenizer matches tags by their names in the input.

    By default, tags aren't renamed.

    Type Declaration

      • (name: string): string

      • Parameters

        • name: string

          The tag name as it appears in the input.

        Returns string

        The tag name that the parser uses.

    Example

    createDOMParser({ renameTag: name => name.toLowerCase() });

    Optionaltokenizer

    tokenizer?: Tokenizer

    The tokenizer that reads tokens for the parser. Parsers that share a tokenizer share its resolved options, so create a tokenizer once and pass it to every parser that reads the same markup.

    Example

    import { createDOMParser, HTMLTokenizer } from 'tag-soup';

    createDOMParser({ tokenizer: HTMLTokenizer });

    Default

    createTokenizer()

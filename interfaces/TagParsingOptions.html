    OptionalendTagScopeLevel

    endTagScopeLevel?: number

    The end tag scope level of the tag. An end tag of an enclosing tag doesn't end this tag and the tags inside it if this level is higher than the level of the enclosing tag. Such an end tag is unbalanced.

    For example, in HTML an end tag inside a table cell can't end tags outside the table, but the end tag of a row ends the cell, and the end tag of a table ends rows and cells:

    <div><table><tr><td></div>aaa  →  <div><table><tr><td>aaa</td></tr></table></div>
                        ▔▔▔▔▔▔ Ignored, so "aaa" stays in the cell

    Without end tag scope levels, the end tag of div ends the cell, the row and the table:

    <div><table><tr><td></div>aaa  →  <div><table><tr><td></td></tr></table></div>aaa
                        ▔▔▔▔▔▔ Ends div, so "aaa" follows it

    To achieve this behavior, set tags to:

    {
      td: { endTagScopeLevel: 1 },
      tr: { endTagScopeLevel: 1 },
      table: { endTagScopeLevel: 2 },
    }

    OptionalforeignContext

    foreignContext?: TokenizerContextOptions

    Options of the context that the content of the tag is read in. A tag with these options is a foreign tag. Outer options are restored when the tag is ended. Foreign options don't inherit outer options, but options can reference each other, so foreign content may contain tags that switch back to outer options.

    The foreign tag itself is self-closing if either options recognize self-closing tags.

    For example, in HTML svg content is read with XML rules, while foreignObject inside svg switches back to HTML rules:

    const svgOptions: TokenizerContextOptions = {
      areSelfClosingTagsRecognized: true,
    };

    const htmlOptions: TokenizerOptions = {
      tags: {
        br: { kind: 'void' },
        svg: { foreignContext: svgOptions },
      },
    };

    svgOptions.tags = {
      foreignObject: { foreignContext: htmlOptions }
    };

    OptionalimplicitEndingTagNames

    implicitEndingTagNames?: Iterable<string, any, any>

    The list of tags that implicitly end this tag when they are started.

    For example, in HTML p is implicitly ended by h1:

    <p><h1>  →  <p></p><h1></h1>
                   ▔▔▔▔ p is implicitly ended by h1

    To achieve this behavior, set tags to:

    { p: { implicitEndingTagNames: ['h1'] } }

    Tags are ended by name in any context. A tag inside a foreign tag can end the foreign tag, and then it's read with tags of the outer options. For example, in HTML svg is implicitly ended by br:

    <svg><br>text  →  <svg></svg><br>text
                           ▔▔▔▔▔▔ svg is implicitly ended by br

    To achieve this behavior, set tags to:

    {
      svg: {
        implicitEndingTagNames: ['br'],
        foreignContext: {},
      },
      br: { kind: 'void' },
    }

    isImplicitEndingScope

    OptionalisImplicitEndingScope

    isImplicitEndingScope?: boolean

    If true then the tag is an implicit ending scope: tags that are started inside this tag don't implicitly end tags outside of it. A scope that is implicitly ended itself doesn't limit anything.

    For example, in HTML li is implicitly ended by li, but only inside the nearest list:

    <ul><li><ul><li>  →  <ul><li><ul><li></li></ul></li></ul>
                                     ▔▔▔▔ Outer li isn't ended by the nested li

    To achieve this behavior, set tags to:

    {
      li: { implicitEndingTagNames: ['li'] },
      ul: { isImplicitEndingScope: true },
      ol: { isImplicitEndingScope: true },
    }

    Default

    false

    OptionalisImplicitlyStarted

    isImplicitlyStarted?: boolean

    If true then a start tag is inserted before an unbalanced end tag of this tag. Otherwise, the end tag is ignored or rejected, see TokenizerOptions.areUnbalancedEndTagsIgnored.

    For example, in HTML p and br tags follow these semantics:

    </p>   →  <p></p>
              ▔▔▔ p is implicitly started

    </br>  →  <br>
              ▔▔▔▔ br is implicitly started

    To achieve this behavior, set tags to:

    {
      p: {
        isImplicitlyStarted: true
      },
      br: {
        kind: 'void',
        isImplicitlyStarted: true
      },
    }

    An end tag of an implicitly started tag doesn't end the tag across an implicit ending scope that its start tag doesn't end. A start tag is inserted instead:

    <p><button></p>  →  <p><button><p></p></button></p>

    Default

    false

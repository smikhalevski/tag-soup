    Type Alias TagKind

    TagKind: "normal" | "void" | "raw_text" | "escapable_raw_text" | "script_data"

    The kind of a tag, which defines what the tag can contain, and how parsers read it and serializers write it:

    normal
    Tag can contain tags and text. Parsers decode this text with ParserOptions.decodeText, and serializers encode it with SerializerOptions.encodeText.
    void
    Tag can contain nothing. Tokenizers insert an end tag right after the start tag, and serializers write an element without children as a start tag only.
    raw_text
    Tag can contain text up to the matching end tag. Parsers don't decode this text, and serializers write it as is.
    escapable_raw_text
    Same as raw_text, but parsers decode the text, and serializers encode it.
    script_data
    Same as raw_text, but after <!-- a start tag of the same name hides end tags until its own end tag or -->. Browsers read script this way for compatibility with old scripts wrapped in comments:
    <script><!--<script></script></script>
                                 ▔▔▔▔▔▔▔▔▔ Ends the script

    In raw text of any kind, an end tag must be followed by a space, / or >, so </script at the end of the input is text.
